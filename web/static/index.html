怎么拿 key

  
万相（必需）：platform.qianwenai.com/try-ai?scene=video → 万相 3.0-视频生成 → 右上角「获取 API Key」。480P/2s ¥0.40。

  
大模型（必需）：DeepSeek，模型 deepseek-v4-pro（实测能看图挑帧；v4-flash 不能）。写提示词 + 看联络表 + agent 大脑都用它。

  
中转站（出立绘要）：关键：必须支持 gpt-image-2.5（出立绘和图生图改版都靠它，别的图像模型没实测过）。推荐 jizhiapi.site（邀请码 9GKRGQJNL4R4），¥0.05/张；baseUrl 填 https://jizhiapi.site/v1，model 填 gpt-image-2.5，每次价格填 0.05。其它 OpenAI 兼容站也行，保存后「检查」能列出它的图像模型 —— 列表里没有 gpt-image-2.5 就换一家。已有立绘可不配。

  
智谱（可选）：CogVideoX-3 会推镜头、转正面，只适合探静止型；买了包填包价。
