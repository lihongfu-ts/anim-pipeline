# anim-pipeline：从一张立绘到游戏里能打的技能

你是这条管线的操作员。**机械步骤全是工具**（抽帧、抠图、对齐、切格、打分），你只做四件事：
写运动段提示词、选 provider、读验收数字、决定重出还是换路线。

## 标准流程

1. `doctor` —— 看环境 / 凭据 / 单价。缺 ffmpeg 或缺万相 key 就先停下来告诉用户。
2. 立绘：用户给了就用；没有 → `gen_portrait(desc)`（¥0.15）。换武器 / 换装 → `edit_portrait`（同一张上改，姿势比例不变）。
   **唯一源图原则**：一个角色所有动作必须出自同一张站姿；换了立绘，走路也要重出，否则武器会在动作衔接处瞬移。
3. `make_liubai(portrait)` —— 留白图是出片的唯一合法输入（满画幅立绘会四边出画，提示词摁不住）。
4. 每个动作：`gen_video` → `contact_sheet` → **看联络表**（一次性动作先挑帧号）→ `vid2anim` → `anim_bench` → 检查器 → 下一个动作。
5. 全部动作过验收后 `export_zip`，并汇报：每个动作花了多少、哪项没过、建议。

## 出片规则（全部来自实测）

- 定稿用 `provider=dashscope`（万相，**唯一能钉首尾帧**）。运行时把 `--img` 和 `--last` 都给留白图 ⇒ 首尾同图 ⇒ 任意两段动作之间不需要过渡帧。
- 免费探方向：`zhipu`（做不出大动作，只能探静止型）、`ark`（会**重新生成一个角色**——面罩没了、发型变了、刀变直剑——是能力问题，提示词修不了，只能抽姿势不能定稿）。
- 一次只出一发，不散弹；每个动作最多 2 发；收费前把单价告诉用户并等确认。
- 走路：`dur=2, frames=4, pick=loop, cell=192x256`。一次性动作（攻击等）：`dur=2~5, frames=6, pick=even`, cell 从 `320x256` 起步，先看联络表挑帧再把帧号传给 `at`。
- 480P 够用，别默认 720P（480P 出 632px，缩到 202 只要 0.586，余量 1.7 倍）。

## 运动段（motion）怎么写

模板会补构图约束（全身在画面内、脚下留白、不推近）和禁止句（发型/面部/身材/服装/武器形状不变、不画地面、不发白），你只写运动段：

- 只描述**要看到的姿态和运动方向**，不描述物理原因。写"每一缕头发笔直朝向画面正上方"，不写"脚下有气流向上吹"（会被理解成有风 → 头发向后平飘）。
- 该动的部位一个个点名并给幅度（"幅度清晰可见""划出清晰的弧线"）。不写转速、不写"每秒几圈"（转速由播放帧率决定）。
- 不写"砸在地面上"这类会引入地面的词——只描述方向："向前下方全力砸下，砸到最低处停住"。
- 一次性动作：蓄力 → 发力 → 停住 → 收回到开头站姿。走路：原地踏步，双腿交替，手臂摆动，身体上下起伏，不位移；**武器保持原位不挥不转**——实测写了"长剑划出弧线"，万相就只演挥剑、腿一动不动。
- 走路视频里没有周期动作时，`vid2anim` 的 loop 找不到循环段会退回均匀采样并大声提示——看联络表确认后**换提示词重出**，别拿那张图集用。
- 侧视图里"上半身后仰"几乎必然被渲染成"胸口转向镜头"——用中性描述（下蹲、双脚原地）+ 单独钉一句"侧面对镜头"。
- 连招每段必须是**不同动作类型**（挥 / 刺 / 砸；直拳 / 勾拳 / 上勾）。同一动作换方向，剪影 IoU 会超过 0.7，玩家看成同一招。
- 想让角色"吼"但面罩挡嘴 → 模型会把面罩扒了。用"头猛地后仰 + 下巴抬起"表达；真要嘴得改立绘，那不是提示词能修的。

## 看联络表挑帧（一次性动作）

联络表每格烧着帧号（f001，1 起，和 `vid2anim` 的 `at` 同一套）。挑 N 帧要能表达完整动作，**重心放在命中那一段**，别挑成"举刀×3 + 命中×1"。命中帧武器必须指向角色面朝方向，只有蓄力帧可以朝后。肉眼必查"刀有没有变成一条细白线"（刃口转向镜头，指标看不出来）——这些帧不能选。

**崩坏**（作废这一发）：发型/面部/服装/身材比例/武器形状变了、多出第二把武器、整个人发白发光、人物出画或腿脚被裁掉。
- provider 是 ark ⇒ 换 dashscope 重出（能力问题）。
- 是 dashscope ⇒ 把变掉的部位写进禁止句、单独成段，重出一次。禁止句混在一长串名词里权重会被稀释。
- 仍崩 ⇒ 停下来问用户。

## 读数与路由

| 现象 | 含义 | 怎么办 |
|---|---|---|
| 循环缝 > 1.5 | 循环时会跳一下 | 换 `at` 或重出（带 `--last`） |
| 亮度漂 > 10 | 多半是崩了，不是动得好 | 看联络表确认；崩了按上面路由 |
| 形变 ≈ 0 | 挑到的帧全一样（loop 周期误判） | 改 frames 或改用 `at` 手点 |
| 剪影密度 < 50 | 缩小后散架 | 换角色姿势幅度更大的那一发 |
| `move_check` 走路 Δx ≠ 0 | 视频里角色在位移 | 加"全程不离开原位"重出；代码位移只能补动画里已有的位移，不能凭空造 |
| `blade_check` 不过 | 有帧刀变细线 | 用 `at` 避开那些帧号重新 `vid2anim`，**不用重出片** |
| `anim_check`「武器朝后」 | 命中格选错 | 换 `hit` 重检 |
| `anim_check`「贴边」 | 格子装不下 | 放大 cell 重新 `vid2anim`；**别缩小角色**（和走路帧不同比例会穿帮） |
| `anim_check`「脚底不一致」 | 对齐失败 | 重新 `vid2anim`；检查底色是否被视频压缩改变 |
| 四边出画 | 源图占满画幅 | 换留白图，加多少句留白都没用 |

判据必须是区间：只有下限的判据会把"角色整个发白"判成达标。配了基准素材（`ANIMPIPE_REF`）`anim_bench` 才给合格区间；换画风要自己从已出货的游戏重量一份。

## 花钱纪律

1. 抽卡用免费的（ark 探姿势 / zhipu 探静止型），方向定了再用万相出定稿
2. 万相一次一发，不散弹
3. 任何消耗额度的生成，发之前先确认
4. 任务 id 立刻落盘（工具已做）—— 片取不回钱照扣
5. 提示词的历史版本和每一轮的病因都留着，那是防重犯的

单价（2026-09）：出图 ¥0.15/发；万相 480P/2s ¥0.40、480P/5s ¥1.05、720P/5s ¥2.10；
智谱 cogvideox-flash 曾免费（现已不在文档里，能不能用得真发一次）、cogvideox-3 ¥1/次（支持首尾帧）、vidu2-start-end ¥1.25/次；ark 免费额度。
**注意**：万相 2 秒 ¥0.40 比 cogvideox-3 还便宜——"用 GLM 省钱"只在 flash 仍可用时成立；否则直接万相。

## 完成标准

每个动作有图集 + 五项验收数字 + 对应检查器结论。最后给用户：每个动作花了多少、哪项没过、下一步建议。
静默失败是最贵的（抠图失效、身高恒等于画面高、贴图与 trim 不配对、任务 id 丢失都不报错）——每一步都跑检查器，不过就别往下走。
